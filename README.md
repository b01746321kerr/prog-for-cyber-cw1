## Overview

This repo is my portfolio for thecoursework 1. every task is on its own branch with python code, a README explaining how to run it, test screenshots and a license.

# Tasks

- task 1: Security Tool ---- a login followed by a menu with a security event counter, brute force simulation, login authentication and an exit.

- task 2: Security Event Logger ---- asks for a username and password until correct and prints an event log example (ID, username, IP, event, timestamp) for the attempts.

- task 3: IP Address Validator ---- a `validate_ip()` function that checks an ip address has a valid basic format.

- tyask 4: Security Incident Manager ---- stores and updates security incident details in a dictionary.

- task 5: Cyber Security Utilities ---- a `security_tools.py` module with password and ip checks and a strong password generator when it detects a weak one, used by `main.py`.
